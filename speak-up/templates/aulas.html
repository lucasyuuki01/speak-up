Como ler a pronúncia simplificada
  • É uma aproximação feita com letras do português. O som do inglês não é exatamente igual.
  • rr é um "h" soprado, bem leve: hello → rrelôu.
  • th é feito com a ponta da língua entre os dentes: three → thrí.
  • â é um som neutro e curtinho: bus → bâs.
  • Use os botões 🔊 para ouvir e 🐢 para ouvir mais devagar.
